Index Language API

Documentación sencilla de todos los endpoints. Solo existen dos idiomas: EN (inglés, predeterminado) y ES (español).

Importante: Esta API solo entrega traducciones. No guarda preferencias de servidores ni tiene nada de Discord. El bot Index se conectará después.

Endpoints disponibles

GET /

Información general de la API (nombre, versión, estado, idiomas y lista de endpoints).

Ejemplo de uso:

curl http://localhost:3000/

Respuesta de ejemplo:

{
  "name": "Index Language API",
  "version": "1.0.0",
  "status": "operational",
  "description": "...",
  "defaultLanguage": "EN",
  "languages": ["EN", "ES"],
  "endpoints": [ ... ]
}

GET /health

Comprueba si la API está funcionando. Útil para Render y monitoreo.

curl http://localhost:3000/health
{
  "status": "ok",
  "version": "1.0.0",
  "timestamp": "2026-10-13T18:00:00.000Z"
}

GET /languages

Lista los idiomas disponibles y cuál es el predeterminado (siempre EN).

curl http://localhost:3000/languages
{
  "success": true,
  "defaultLanguage": "EN",
  "languages": [
    { "code": "EN", "name": "English" },
    { "code": "ES", "name": "Español" }
  ]
}

GET /languages/:lang

Devuelve todo el catálogo de traducciones de un idioma.

Valores válidos de :lang: EN o ES (mayúsculas o minúsculas).

Ejemplos:

curl http://localhost:3000/languages/EN
curl http://localhost:3000/languages/ES

Respuesta de ejemplo (resumida):

{
  "success": true,
  "language": "ES",
  "translations": {
    "common": { "yes": "Sí", "no": "No", ... },
    "errors": { "no_permission": "No tienes permisos...", ... },
    "tickets": { ... },
    ...
  }
}

Error 400 si pones un idioma que no existe (ej: FR, PT, etc.):

{
  "success": false,
  "error": "Unsupported language \"FR\". Available languages are: EN, ES."
}

GET /languages/:lang/:key

Devuelve una sola traducción por su clave.

La clave usa puntos, por ejemplo: errors.no_permission, tickets.created, common.yes.

Ejemplos reales:

curl http://localhost:3000/languages/ES/errors.no_permission
curl http://localhost:3000/languages/EN/errors.no_permission
curl http://localhost:3000/languages/ES/tickets.created
curl http://localhost:3000/languages/EN/common.yes

Respuesta correcta:

{
  "success": true,
  "language": "ES",
  "key": "errors.no_permission",
  "text": "No tienes permisos para utilizar este comando."
}

Error 400 – idioma no válido:

{
  "success": false,
  "error": "Unsupported language \"FR\". Available languages are: EN, ES."
}

Error 404 – la clave no existe:

{
  "success": false,
  "error": "Translation key \"foo.bar\" not found for language EN."
}

Algunas claves útiles (ejemplos)

Clave EN ES
errors.no_permission You don't have permission... No tienes permisos...
errors.cooldown You are on cooldown... Estás en tiempo de espera...
tickets.created Your ticket has been created... Tu ticket ha sido creado...
welcome.message Welcome to **{server}**... ¡Bienvenido a **{server}**...
general.ping Pong! Latency: {latency}ms ¡Pong! Latencia: {latency}ms
common.yes / common.no Yes / No Sí / No
Las llaves entre llaves {user}, {server}, {latency} etc. las reemplazará el bot Index más adelante. La API solo entrega el texto.

Cómo lo usará el bot Index (futuro)

  1. El bot llama a /languages para saber que existen EN y ES.
  2. Guarda en su propia base de datos qué idioma quiere cada servidor de Discord.
  3. Cuando un usuario usa un comando, el bot pide la traducción con:
    GET /languages/ES/errors.no_permission (o EN).
  4. Si el servidor no tiene idioma configurado → usa EN (el predeterminado).
